## Authority and status rules
- Latest direct author instruction controls within its stated scope.
- Preserve original owners; this handoff index is a route, not a replacement source.
- Distinguish PROPOSED, AUTHOR_SELECTED, PREPARED, DELIVERED_PROVISIONAL, AUTHOR_ACCEPTED and INSTALLED_READBACK.
- Delivery does not establish author acceptance.
- WORK advances zero fictional time. PLAY requires explicit authorization.
- Do not infer that a planned T.P.P. appearance, reunion, lyric performance or character action has occurred unless the delivered manuscript and matching checkpoint establish it.
- Check live CURRENT and DELIVERY_LEDGER before continuing.

## Scope / packaging note
This folder currently contains a verified README index linking to existing canonical repository sources; the source files remain at their original paths and are not duplicated here. It is not yet a self-contained offline mirror. To create one, copy the complete owner files unchanged into subfolders here and verify each copied file against its source hash from the manifest/index. Do not replace full source files with summaries.
